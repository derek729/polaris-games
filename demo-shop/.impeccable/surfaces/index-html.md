# Surface brief — demo-shop/index.html (프리미엄 패션 몰 데모)

스코프: 단일 페이지 데모 쇼핑몰 (히어로 + 드롭 스케줄 + 컬렉션 그리드 + 상품 시트 + 푸터).
방문자 모드: **Persuade** — 방문자가 컬렉션 드롭을 이해하고, 룩을 열어보고, '선택' 액션을 취하게 만든다.

- 청중: 폴라리스 개발 담당자(디자인 품질 평가자) — 한국어, 와이드 데스크톱 브라우저에서 몇 초 안에 판단.
- 과업: 프리미엄 패션 하우스의 컬렉션 드롭 페이지가 진짜 하우스처럼 읽히는지 확인.
- 행동/증명: 합성 컬렉션(전체 라벨), 상품 상태(라이브/드롭 예정/품절), 드롭 카운트다운.
- 제약: 무빌드 단일 HTML, 실거래 없음, 상업적 사실 주장 금지, 합성 콘텐츠 명시 라벨.

## Direction contract

THESIS: 카탈로그는 분광 계측기다 — 모든 상품이 하나의 캘리브레이션 레일에 등록된 방출선이고, 색은 오직 물리적으로 의미 있는 파장 헤어라인으로만 존재한다. 카테고리의 디폴트(화이트 그리드 셀렉티브샵)와 그 반대(골드 세리프 다크 럭셔리) 둘 다 거부한다.

OWN-WORLD: 따뜻한 charcoal 연속체(밴드 차이로만 깊이, 그라데이션 금지), 본(bone) 레전드, 7파장 헤어라인(405/436/486/546/589/615/656nm — 589 나트륨선은 이중선), 상태는 색이 아니라 선의 형태(실선=라이브, 대시=드롭 예정, 반높이=품절임박, 취소선=품절). 타입은 단일 그로테스크 — 위계는 사이즈가 아니라 트래킹과 잉크로. 숫자는 태블릴러. 이미지는 전부 그래파이트로 매트, 1px 라인 에지.

STORY: 방문자는 첫 뷰포트에서 "이 하우스는 컬렉션을 측정해서 보여준다"는 하나의 아이디어를 얻는다 → 레일의 랜딩선이 스프링 한 번으로 제자리에 닿는다 → 틱을 따라 컬렉션을 훑고 → 상품 틱을 열면 자이언트 플레이트가 레일 위에 피오르고 뒤 시트는 한 단계 어두워진다 → 드롭 스케줄의 나트륨 이중선이 '지금'을 가리킨다 → 선택(장바구니 담기)은 레일에 또 하나의 선분을 남긴다.

FIRST VIEWPORT: 좌측 ~13% 지점에 오프센터 수직 레일(380–700nm 눈금, 하단 계기 침반 밴드). 하우스명 MONO™ 와 원라인 채널 문장은 본 레전드 마이크로 캡 + 트래킹. 오프닝 플레이트(이번 드롭 룩 사진, 그래파이트 매트)가 레일 우측에 크게; 주 액션 '룩 열기'는 레일에 등록된 틱 버튼. 우상단 나트륨 589 이중선이 에디터 선호 표시로 유일하게 이웃보다 높다.

FORM: 방출선 레일 — 롤이 지정한 챌린저가 이겨서 채택 (seed key af453898, catalog: operate-c-emission-line-rail). 내 7후보 중 4번(아틀리에 인보이스 계열 제도 문법)과 같은 제도 family.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
