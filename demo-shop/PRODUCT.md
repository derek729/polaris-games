# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

정적 단일 HTML 파일 (부모 repo polaris-games의 무빌드 관례 승계 — 이미 코드베이스가 답함)

## Users

사용자 본인(폴라리스 개발 담당자). 브라우저에서 데모 페이지를 열어 디자인 출력 품질을 육안 평가한다. [요청문 직접 근거: "디자인이 제대로 나오는지 확인 하게"]

## Product Purpose

디자인 품질 검증용 샘플 쇼핑몰 페이지. 실제 판매·거래는 없다. 성공 = 사용자가 한 번 훑어보고 "디자인이 제대로 나온다"고 판단할 수 있는 수준의 첫인상과 완결도.

## Positioning

실제 제품이 아니다 — 디자인 역량 시연 아티팩트. 이웃 제품이 베낄 수 있는 고유 메커니즘 같은 건 없고, 검증 대상은 시각적 완성도 자체.

## Operating Context

부모 repo(polaris-games)의 정적 호스팅 환경. 파일을 브라우저로 직접 열거나 정적 서버로 띄워 확인. 빌드 단계 없음.

## Capabilities and Constraints

- 단일 페이지 데모: 히어로 + 큐레이션 상품 목록 + 룩/에디토리얼 구간 + 푸터 수준의 구성
- 실거래 기능(장바구니 결제 등) 없음 — 시각적 시연에 필요한 상호작용만
- 모든 상품·가격·브랜드 콘텐츠는 합성(synthetic)이며 실제라는 착시를 주는 수준의 완성도로, 상업적 사실 주장은 만들지 않음
- 한국어 카피

## Brand Commitments

- 컨셉: **프리미엄 패션 몰** (사용자가 탐색 질문에서 직접 선택 — 시각 세계 결정은 new-work 소관)

## Evidence on Hand

없음. 실제 고객 후기·언론 보도·판매 데이터 부재 — 향후 작업도 이를 날조하지 말 것. 합성 콘텐츠만 허용.

## Product Principles

1. 한 번 뷰포트를 봐도 한 시간 뒤에 묘사할 수 있는 첫인상 — 무드가 아니라 구조로 기억되게
2. 데모여도 프로덕션 품질: 실존 쇼핑몰과 구분 안 될 완결도
3. 합성 콘텐츠는 진짜처럼, 사실 주장은 없게
