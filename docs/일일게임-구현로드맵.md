## 0. 파이프라인 (매일 반복)

1. **선정** — 아래 목록에서 ⬜(미완료) 2개 이상 선택. 목록이 얇아지면 새 후보를
   추가하되, 레퍼런스 저장소 존재는 `git ls-remote`로 먼저 검증한다.
2. **REA 분석** — 레퍼런스를 `/tmp/ref-games/<게임>`에 얕은 클론 후
   `rea analyze <디렉터리>`로 애플리케이션 구조(Evidence 그래프)를 재구성하고,
   핵심 모듈에서 메커니즘(스폰 규칙·점수 공식·난이도 곡선·판정)을 추출한다.
3. **자체 구현** — 워크스페이스 컨벤션(단일 HTML, 한국어 UI, 다크 테마,
   PWA 메타, localStorage 최고기록, 모바일 터치)으로 처음부터 재구현한다.
   **레퍼런스의 코드·에셋을 복사하지 않는다** — 규칙과 설계만 참조한다
   (docs/오픈소스게임-에셋활용후보.md §0 원칙 준용).
4. **등록** — index.html 포털에 카드 추가.
5. **검증** — `python3 -m http.server` + Chrome headless 스크린샷 + 페이지 자체
   `#selftest` 모드로 로직 무결성 확인.
6. **기록** — 개별 커밋 `feat: <게임명> — REA 레퍼런스 분석 기반 신규 게임 (BACKLOG #N)`,
   이 문서의 상태를 ✅(완료일 포함)로 갱신.
