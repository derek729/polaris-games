## 0. 조사에서 확인된 라이선스 제약 (가장 중요)

**Infinity Blade 팩은 Epic이 "UE-Only"로 라이선싱한 콘텐츠다.**
Epic이 2018년 무료 공개할 때부터 Marketplace/Fab 콘텐츠 EULA상 "Restricted
Content"로 분류되어 **Unreal Engine 기반 제품에만 사용할 수 있다.**
(UE 포럼 답변: "Infinity Blade assets are marked as UE4-Only" 확인됨)

이에 따른 우리 쪽 정리:

1. **웹(Three.js) 프로토타입에 쓴 추출 텍스처는 EULA 위반 소지** →
   웹 버전은 절차적 텍스처 또는 자체 제작 텍스처로 교체하는 것이 안전하다.
   (TODO로 추적)
2. 에셋을 합법적으로 쓰는 길은 **UE 네이티브 경로(P3)** 하나다.
3. 오픈소스 게임은 **에셋을 넣는 대상**이 아니라 **메커니즘·설계를 참조하는
   소스**로 활용한다 (게임 규칙/아이디어는 저작권 대상이 아님).

이 기준으로 후보를 두 트랙으로 나눈다.

## 우리 로드맵과의 연결

| 우리 단계 | 참조할 후보 |
|---|---|
| P0 웹 프로토타입 다듬기 | Ikemen GO(라운드·히트스톱), Lugaru(반격·텔레그래프), DCSS(보스 패턴 밸런스) |
| 웹 버전 라이선스 정리 | **에셋 텍스처 → 절차적/자체 텍스처 교체 (필수 TODO)** |
| P2 콘텐츠·멀티 확장 | BrowserQuest·Stendhal(웹 멀티 구조), Flare(ARPG 시스템) |
| P3 UE5 네이티브 | **A트랙 전부** — Action RPG 샘플 + IB 에셋 리스킨 (라이선스 안전) |

## 추천 쇼트리스트 (Top 3)

1. **Ikemen GO** — 1:1 결투 장르가 완전히 같다. 판정·연출 설계를 그대로 벤치마킹.
2. **Epic Action RPG 샘플 + IB 에셋** — UE 경로에서 에셋을 합법적으로 즉시 투입할 수 있는 가장 빠른 차량.
3. **Lugaru** — 가벼운 코드량의 근접 반격 전투 원형. 우리 판정 시스템(패리 창) 설계 검증용.
