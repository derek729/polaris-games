## E2E에서 발견해 수정한 버그

1. **장애물 충돌 전무 (실버그)** — `buildDungeon`이 장애물 목록(`placed`)을
   `DUNGEON.obstacles`에 복사하지 않아 기둥·바리케이드를 통과하는 문제. 복사
   한 줄 추가 후 T4 통과(정확히 반경 0.85에서 저지).
2. **영지 자동 개방이 게임을 몰래 일시정지** — 접근 시 메뉴가 자동으로 열려
   게임이 조용히 멈추는 문제. **E키 상호작용**으로 변경(조작 안내 배너 표시).
3. 영지에서 체력 스탯 상승 시 현재 체력도 +12 반영되도록 수정.
4. 테스트 하네스 이슈(제품 버그 아님): 모듈 로드 완료 전 클릭 무시,
   상자 체력 클램프가 테스트용 고체력을 되돌리는 현상 — 각각 대기/보정 처리.

## 재실행 방법

테스트는 브라우저 콘솔/자동화에서 `window.DBG`(게임 상태)·`window.RPG`(룬)·
키 이벤트 디스패치 방식으로 구동된다. 시나리오 목록은 본 표 참조.
주의: 페이지 reload 후에는 `window.__e2e` 하네스가 사라지므로 재초기화 필요,
모듈 평가 완료 전 클릭은 무시된다(`window.RPG` 폴링 후 진행).
