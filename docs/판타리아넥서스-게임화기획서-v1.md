# 《판타리아 넥서스》 게임화 기획서 v1

> 2026-09-27 작성 · 원본: 사장님 집필 웹툰 IP 《판타리아 넥서스》(145화+ 연재) +
> 《개정판 게임요소 반영 요약본(확정본)》 + 제작 데이터(fantasia.zip: music/imag/obj/pro)
> · 베이스 엔진: 잉걸불의성 실시간 ARPG(Three.js, 검증 완료)

---

## 1. IP 개요 (Drive 자료 기반 확인 완료)

- 웹툰 145화 이상 연재 + 소설 《망각의 검모와 개어난 세계》 1~2권
- 게임 시스템 설계가 **확정본 문서로 존재** (요약본: 반영 10항목 + 추가 예정 8항목)
- 제작 데이터(음악/이미지/오브젝트/프로그램)가 이미 게임 제작 형식으로 정리됨
- **결론: 콘텐츠 리스크 없음. 기획서→엔진 연결만 남은 상태.**

## 2. 세계관 핵심 (원문 기반)

주인공 **강민준**이 '판타리아 넥서스'에 접속하며 **현실과 게임의 경계가 무너진다**.
UI(상태창·시나리오 경고창·후원자 메시지)가 현실에 시스템화되고, 시즌 몬스터·
정화/감염 구조의 전투, 그림자 계약(강화와 정신 오염 동시 반영), NPC 엘시아·제논과의
감정·진로 분기가 이어진다.

→ **지금 만든 실시간 ARPG(게임 UI 연출·루른 경제·던전)와 톤/구조가 일치.**
→ 차이는 '리스킨' 수준이 아니라 IP 콘텐츠 이식 + 신규 시스템 3종(펫·골렘·후원자).

## 3. 시스템 매핑표 (확정본 게임요소 → 구현 계획)

| 원작 게임요소 | 현황 | 계획 |
|---|---|---|
| 몬스터 전투(보스·정화/감염 구조) | ✅ 실시간 전투 구현됨 | **감염 몬스터** 신규 타입 추가(처치 시 오염 확률) |
| 시나리오 기반 퀘스트(제한형 미션) | ⬜ 던전 층 구조 있음 | 층마다 제한시간/실패조건 미션 부여 |
| 장비 강화/파괴(조각화·강화 실패) | ◑ 숫돌 강화만 있음 | **강화 실패 → 파괴/조각화** 시스템 추가 |
| 펫/테이밍(펜리르, 유대/전투 보조) | ⬜ | 몬스터 테이밍 → 동행 전투 보조 |
| 골렘 육성(스크랩→진화) | ⬜ | 던전 스크랩 수집 → 골렘 동료 진화 |
| 후원자 시스템(선/악 분기) | ⬜ | **후원자 2인(선/악)** — 행동 로그에 따라 메시지·보상 분기 |
| UI 시스템화(상태창·경고창·후원자 메시지) | ◑ HUD 있음 | 원작 톤의 게임UI 연출 프레임 적용 |
| 그림자 계약(정신 오염) | ⬜ | 강화 실패 누적 → 오염 디버프(서사 연동) |
| NPC 협력(엘시아·제논, 진로 분기) | ⬜ | 스토리 모드에서 동료 선택 분기 |

## 4. 성장·경제 (룬 시스템 유지 + 확장)

- 룬 = 원작의 게임 화폐로 리브랜딩 (현실-게임 경계 붕괴 설정과 일치)
- 사망 시 룬 드롭·회수 루프 유지 (엘든 링식, 이미 검증됨)
- 상점: 회복 물약·무기 숫돌·갑옷 보수 유지 + **악세서리 슬롯**(반지·팔찌·허리띠 —
  확정본 '추가 반영 예정' 항목)은 Phase B

## 5. 개발 로드맵

| 단계 | 범위 | 산출 |
|---|---|---|
| **A. 리브랜딩 (1스프린트)** | 타이틀·HUD·문구를 판타리아 넥서스 톤으로, 감염 몬스터 1종, 강화 실패/조각화 | 판타리아 넥서스 첫 플레이버전 |
| **B. 동료 시스템 (2스프린트)** | 테이밍(펜리르)·골렘 육성·후원자 2인 분기 | 빌드 다양화 |
| **C. 경제 확장 (3스프린트)** | 악세서리 슬롯·웹 시세 연동·미니게임(빠칭코/경마/복권 — 두마당 자산 시너지) | F2P 수익 구조 |
| **D. 스토리 모드** | 강민준 시나리오·엘시아/제논 분기·145화 연계 에피소드 | 정식 버전 |
