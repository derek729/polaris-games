- project.godot: config/version "0.15.1" → "0.15.3".
- **Web 프리셋 export 불가 확인** — 설치된 Godot이 Mono 빌드(4.7.2.mono)라

- 산출 pck을 release/gostop-v0.15.3-web.pck에 반영 → rebuild-gostop-zip.py로
