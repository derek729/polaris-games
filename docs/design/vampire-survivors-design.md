## 1. 목표

현재 게임은 밸런스 테이블(웨이브·무기·진화)은 완성도가 높지만, ① 타격이 "숫자만 뜨고" 무덤덤하고, ② 레벨업 3택이 굴리는 RNG에 100% 좌우되어 주도권이 없으며, ③ 10분 런이 끝나면 성취가 화면에서 사라진다(요약 부재, 메타 진행 없음). 이번 스프린트는 **새 밸런스 테이블 없이** 기존 루프의 세 지점 — 타격감(주스), 선택의 주도권(리롤/스킵/진화 예고), 런의 마무리(종료 요약) — 만 보강해 "한 판만 더"를 만든다. 모든 변경은 단일 파일·file:// 호환·기존 스프라이트/사운드 폴백 패턴 유지 조건 하에 구현한다.

## 2. 개선 항목

### 항목 1. 주스 패스 — 히트스톱·엘리트 처치 연출·크리티컬 강화 (M)

**배경**
리서치 브리프 (4)-1: *"주스 패스: 적 피격 플래시, 엘리트 히트스톱 40ms, 화면 흔들림, 데미지 숫자 — 구현비 대비 체감 최고"*. 브리프 (2): *"레이어드 피드백 = 흔들림 + 히트스톱(30~60ms) + 파티클 + 플래시 + 사운드"*.

> 코드 확인: **피격 플래시(`dealDmg`의 `e.flash = 0.13` + `drawEnemy` 흰 오버레이), 데미지 숫자(`addText`), 화면 흔들림(`G.shake`)은 이미 존재한다.** 따라서 이 항목은 신규 구축이 아니라 **부족한 레이어(히트스톱, 엘리트/보스 처치 연출, 크리티컬 시각 차등, 저체력 긴장감)만 추가**한다.

**명세**

1. 히트스톱 (월드 슬로모션)

| 트리거 | 히트스톱 시간 | 비고 |
|---|---|---|
| 엘리트 처치 | **0.05초** | |
| 보스 처치 | **0.09초** | 브리프 상한 30~60ms를 보스는 상회(클라이맥스 연출) |
| 플레이어 피격 | **0.04초** | |

- 동작: `update(dt)` 진입 시 `G.hitstop > 0`이면 `G.hitstop -= dt` 후 게임 전체 dt에 `× 0.12` 적용(완전 정지가 아닌 12% 슬로모션 — 타격감 유지, 입력 끊김 방지).
- 동시 상한: `G.hitstop = Math.max(G.hitstop, 값)` — 누적으로 0.09초를 넘기지 않음.
- 런당 총 발생 ≤ 5(엘리트) + 3(보스) + 피격 수 회 → 누적 1초 미만, 10분 타이머(`G.t`) 왜곡은 무시 가능.
- 레벨업/상자 씬으로 전환될 때 `G.hitstop = 0` 리셋(복귀 직후 잔여 슬로모션 방지).

2. 엘리트/보스 처치 연출 (`killEnemy` 내 분기)

| 대상 | 파티클 `burst` 수 | 링 이펙트 | shake | 사운드 |
|---|---|---|---|---|
| 일반 (현행 유지) | 6 | 없음 | 없음 | `SFX.pop()` |
| 엘리트 | **18** | `type:"ring"`, 반경 `e.r*3`, 지속 0.35초 | **+5** | `playSfx("explosion", { volume: 0.35 })` |
| 보스 | **30** (현행 24→30) | 동일 링 추가 | 12 (현행 유지) | `SFX.bossdie()` (현행 유지) |

- 링 이펙트는 기존 `G.effects`의 `"ring"` 타입(폭탄/진화에서 사용 중)을 재사용 — 신규 렌더 코드 0.

3. 크리티컬 텍스트 차등
- 일반: `800 13px`, 흰색 `#ffffff` (현행 유지)
- 크리티컬: **`900 17px`, `#ffd24a`** — `dealDmg`에서 크리티컬 여부를 `addText`에 전달, `drawTexts`에서 폰트 분기.

4. 저체력 비네트 (긴장감)
- `G.p.hp < G.p.maxHp * 0.3` 동안, 월드 렌더 후 전체 화면에 `rgba(255,40,40, 0.10 + 0.06 × sin(now × 0.008))` 단색 오버레이(약 1.27Hz 맥동).

**구현 포인트**
- `newGame()`: `G` 초기화 객체에 `hitstop: 0` 추가.
- `update(dt)`: `luQueue` 체크 직후 히트스톱 감속/슬로모션 3줄 삽입.
- `dealDmg()`: `addText(..., crit)` 시그니처 확장(기존 호출부는 미전달 → 영향 없음).
- `killEnemy()`: `burst` 수치 분기 + 엘리트/보스 링·shake·hitstop·`playSfx("explosion")` 추가(기존 보스 로직 — chest 드롭, 골드 +100, `SFX.bossdie()` — 그대로 유지).
- `damagePlayer()`: `G.hitstop = Math.max(G.hitstop, 0.04)` 한 줄.
- `drawTexts()`: 폰트 분기.
- `render()`: `ctx.drawImage(vignette, 0, 0)` 직후 저체력 오버레이.
- **건드리지 않음**: `WAV_SFX`/`wavBroken`, `SPRITES`/`spriteReady`, `bgmBroken`, `muted`/`toggleMute` — 모든 신규 사운드는 기존 `playSfx` 폴백 경유로 파일 부재 시 조용히 스킵.

**수용 기준**
- [ ] 엘리트(빨간 원 오라 적)를 처치하면 화면이 0.05초간 느려지고 붉은 링 + 파티클 18 + shake가 발생한다.
- [ ] 보스 처치 시 0.09초 슬로모션과 함께 기존 상자 드롭/골드 +100/`SFX.bossdie`가 그대로 동작한다(회귀 없음).
- [ ] 크리티컬 데미지 숫자(도끼/진화 채찍)는 일반 숫자보다 크고 금색이다.
- [ ] 체력 30% 미만에서 화면 가장자리가 붉게 맥동하고, 회복 시 즉시 사라진다.
- [ ] 스프라이트/음성 파일 없는 file:// 환경(폴백 드로잉·무음)에서도 동일하게 동작하며 콘솔 에러 0(`window.__errors` 비어 있음).

**규모: M**

### 항목 2. 레벨업 선택 개편 — 리롤·스킵·진화 레시프 프리뷰 (L)

**명세**

1. 리롤

- 진화 카드 보장: `rollChoices()`는 호출마다 진화 가능 무기를 재선별해 최우선 배치하므로, 리롤해도 진화 선택지는 유실되지 않는다(기존 로직 그대로).

3. 진화 레시프 프리뷰 (카드 배지 + 진행 스트립)

### 항목 3. 런 종료 요약 — 총 피해량·DPS·빌드 리캡·다음 런 목표 (M)

**배경**
리서치 브리프 (4)-10: *"런 종료 요약 화면: 킬·DPS·진화 재료 + '다음 런 목표' 한 줄"*, (1)-5: *"짧고 확정적인 세션 — 명확한 결말이 '한 판만 더'를 유발"*.

> 코드 확인: 종료 화면(`buildEnd`)은 생존시간/레벨/처치/골드만 표시. 피해량 추적(`G.dmgDealt`)이 없고, localStorage 미사용(전체 코드 검증 완료) — 따라서 요약은 **런 내 데이터만**으로 구성하고 메타 저장은 하지 않는다.

**명세**

1. 피해량 추적
- `newGame()`에 `dmgDealt: 0` 초기화. `dealDmg()`에서 크리티컬 배수 확정 후 `G.dmgDealt += d` 한 줄 추가.
- 출처 불문(무기·가랙 오라·성수 웅덩이·폭탄 픽업 400 데미지 전부 포함) — 명세상 의도된 동작.

2. 종료 화면(`buildEnd`) 확장
- `#endStats` 6항목: `생존시간 · 레벨 · 처치 · 골드 ·` **`총 피해량 · DPS`**
  - 총 피해량: `Math.round(G.dmgDealt)` 천 단위 콤마 표기
  - DPS: `Math.round(G.dmgDealt / Math.max(1, Math.min(G.t, GOAL)))` (승리 시 분모 600 고정)
- 빌드 리캡: `#endStats` 위에 `.buildlist` 마크업 재사용(`buildPause`와 동일 슬롯 렌더링: 무기 아이콘 + Lv/★, 패시브 아이콘 + Lv).
- 다음 런 목표 한 줄 — `#endSub` 아래 `<div id="endGoal">` (gold 색상, `.hint` 폰트). 결정론적 3규칙:

| 조건 | 문구 (그대로 구현) |
|---|---|
| 진화 0개 (승패 무관) | `🎯 다음 런 목표: {최고레벨 무기명} 만렙(8) + {전용 패시브명} 획득 → 「{진화명}」` |
| 진화 1개 이상 + 패배 | `🎯 다음 런 목표: 진화 무기 {개수}개 상태로 10분 생존` |
| 진화 1개 이상 + 승리 | `🎉 완벽한 새벽! 다른 캐릭터의 진화 빌드에 도전해 보세요` |

  - 규칙 1의 무기 선택: `G.weapons`에서 `lv` 최대(동률 시 먼저 획득한 것), 진화 전용 패시브명은 `PASSIVES[EVO[id].passive].name`.

**구현 포인트**
- HTML: `#scr-end`에 `#endBuild`(buildlist)와 `#endGoal` 요소 추가.
- JS: `newGame()`(`dmgDealt: 0`), `dealDmg()`(누적 1줄), `buildEnd()`(그리드 확장 + 리캡 + 목표 문기 분기).
- `btnRetry`/`btnHome`의 `G = null` 흐름 그대로 — 다음 `newGame()`에서 자동 초기화되어 회귀 없음.
- **건드리지 않음**: `setScene("over"/"win")` 전환, `stopBgm()`/`SFX` 호출, 승패 판정(`G.t >= GOAL`).

**수용 기준**
- [ ] 사망/승리 모두에서 종료 화면에 총 피해량과 DPS가 표시되고, DPS = 총 피해량 ÷ 생존 초이다.
- [ ] 종료 화면에 해당 런의 무기/패시브 아이콘과 레벨이 일시정지 화면과 동일한 슬롯 형식으로 표시된다.
- [ ] 진화 없이 사망한 런에서 목표 문구가 실제 최고레벨 무기와 그 전용 패시브 이름으로 계산된다(진화 데이터 하드코딩 없음).
- [ ] 승리(10분) 직후 DPS 분모가 600으로 고정된다.
- [ ] "다시 도전" 후 이전 런의 피해량이 남아 있지 않다(0에서 시작).
