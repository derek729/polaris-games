## 1. 검증 완료 — CC0 무료 조합 (권장)

### 캐릭터: KayKit (Kay Lousberg) — CC0 ✅ 실물 검증

GitHub 공식 미러 `KayKit-Game-Assets`에서 다운로드해 glTF 파싱으로 검증했다.
라이선스 원문("Creative Commons Zero, CC0 … free to use in personal, educational
and commercial projects")을 `game-assets/kaykit/LICENSE-*.txt`로 보관.

| 파일 | 크기 | 뼈대 | 애니메이션 | 우리 판정 시스템 매핑 |
|---|---|---|---|---|
| `Knight.glb` (플레이어) | 3.7MB | 41 | 76 | 공격 4종×1H/2H, Block/Block_Hit, Dodge 4방향, Hit_A/B, Death_A/B, Idle_Combat, Taunt |
| `Barbarian.glb` (보스 후보) | 3.6MB | 41 | 76 | 동일 세트 + 2H Spin 등 |
| `Skeleton_Warrior.glb` (적) | 4.9MB | 41 | **95** | 위 + Spellcast(보스 궁극기), Resurrect, Spawn |

- 우리 프로토타입의 절차적 동작(회피/방어/패리/피격/사망)과 **1:1 대응되는
  애니메이션이 전부 내장** — 스테이트머신만 교체하면 된다.
- 같은 팩에 Mage·Rogue·Rogue_Hooded(보스 후보), Dungeon Remastered(모듈형
  던전 아레나, CC0)도 있음.
- GLB = three.js GLTFLoader가 바로 로드하는 표준 포맷.

### 텍스처: ambientCG / Poly Haven — CC0 ✅ (조사 검증)

PBR 석재·금속·목재 텍스처의 표준 CC0 공급처. 현재 웹 프로토타입이 쓰는
IB 추출 텍스처(EULA 위반 소지)의 교체 소스로 사용.

### 기타 무료

- **Quaternius** (quaternius.com) — CC0 저폴리 기사/중세 프롭. 검색으로 CC0 확인.
  KayKit 스타일이 안 맞을 때 대안.
- **poly.pizza** — CC0 모델 검색 엔진 (KayKit/Quaternius 통합 검색).
- **Mixamo** — 무료 캐릭터·애니메이션. 프로젝트 내 사용 가능, 원본 재배포는 금지.
  리얼 인체 애니가 필요할 때.

## 3. 권장 조합 (전부 CC0 → 웹 즉시 합법)

```
플레이어  = KayKit Knight.glb
적 6보스  = Skeleton_Warrior + Barbarian + (Mage/Rogue) → 틴트/스케일 변형
아레나    = KayKit Dungeon Remastered 모듈 + ambientCG 바닥/벽 텍스처
```
