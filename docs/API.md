## 문자열 유틸리티 — `src/utils/str.js`

### 개요

문자열 가공을 위한 유틸리티 모듈이다.

```js
import { capitalize, truncate, slugify } from './src/utils/str.js';

capitalize('hello');        // 'Hello'
truncate('abcdefghij', 5);  // 'abcde…'
slugify('Hello World!');    // 'hello-world'
```

---

### capitalize(s)

문자열의 **첫 글자만 대문자로** 변환하여 반환한다. 나머지 글자는 원본 그대로 유지된다.

#### 시그니처

```js
capitalize(s: string) → string
```

#### 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `s`  | `string` | 예 | 변환할 원본 문자열 |

#### 반환값

| 타입 | 설명 |
|------|------|
| `string` | 첫 글자가 대문자로 변환된 문자열 |

#### 동작 상세 및 엣지 케이스

- 첫 글자를 대문자로, 나머지는 변경 없이 반환한다.
- 이미 첫 글자가 대문자면 원본과 동일한 결과를 반환한다.
- 두 번째 글자 이후의 대문자는 소문자로 바꾸지 않는다 (예: `'hELLO'` → `'HELLO'`).
- 빈 문자열 `''`을 넣으면 빈 문자열을 그대로 반환한다.

#### 예시

```js
capitalize('hello');   // 'Hello'
capitalize('wORLD');   // 'WORLD'
capitalize('');        // ''
```

---

### truncate(s, n)

문자열이 `n`자보다 길면 **앞에서부터 `n`자를 잘라내고 말줄임표 `…`를 붙여** 반환한다.

#### 시그니처

```js
truncate(s: string, n: number) → string
```

#### 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `s`  | `string` | 예 | 원본 문자열 |
| `n`  | `number` | 예 | 유지할 최대 길이 (자릿수) |

#### 반환값

| 타입 | 설명 |
|------|------|
| `string` | 길이가 `n` 이하면 원본 그대로, 초과하면 앞 `n`자 + `"…"` |

#### 동작 상세 및 엣지 케이스

- `s.length > n`인 경우에만 잘라냄: 결과는 `s.slice(0, n) + '…'`.
- `s.length <= n`이면 원본 문자열을 그대로 반환한다 (말줄임표 미추가).
- 빈 문자열 `''`은 조건과 무관하게 `''`를 반환한다.
- `n`이 문자열 길이와 정확히 같으면 원본을 그대로 반환한다.

#### 예시

```js
truncate('abcdefghij', 5);  // 'abcde…' (10자 > 5자이므로 잘라냄)
truncate('abc', 5);         // 'abc'     (길이 이하이므로 원본 그대로)
truncate('abcde', 5);       // 'abcde'   (길이와 같으므로 원본 그대로)
truncate('', 3);            // ''
```

### slugify(s)

문자열을 URL 슬러그 형식으로 변환한다. **소문자로 바꾸고, 공백은 하이픈(`-`)으로 치환하며, `[a-z0-9-]` 외의 문자는 모두 제거**한다.

#### 시그니처

```js
slugify(s: string) → string
```

#### 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `s`  | `string` | 예 | 원본 문자열 |

#### 반환값

| 타입 | 설명 |
|------|------|
| `string` | 소문자 + 하이픈 + 영숫자(`[a-z0-9-]`)만 포함된 슬러그 |

#### 동작 상세 및 엣지 케이스

- 전체를 소문자로 변환한다.
- 공백(스페이스)은 하이픈(`-`)으로 변환한다.
- 그 외 `[a-z0-9-]`에 속하지 않는 문자(특수문자, 대문자, 공백 외 구분자 등)는 제거한다.
- 대문자는 제거되는 것이 아니라 소문자로 변환되어 유지된다.
- 결과가 모두 제거되면 빈 문자열을 반환할 수 있다.
- 한글 등 ASCII 범위 밖 문자는 최종 결과에서 제거된다.

#### 예시

```js
slugify('Hello World');        // 'hello-world'
slugify('Hello  World!');      // 'hello--world'  (!는 제거, 공백 2개는 각각 하이픈)
slugify('Node.js 22 LTS');     // 'nodejs-22-lts' (마침표 . 는 제거)
slugify('!!!');                // ''              (전부 제거됨)
```

> 참고: 연속 공백이 하이픈 여러 개로 변환될 수 있으므로, 슬러그 정규화가 필요한 호출부에서 후처리 여부를 결정한다.

## 수학 유틸리티 — `src/utils/math.js`

### 개요

수치 계산을 위한 유틸리티 모듈이다.

```js
import { clamp, sum, average } from './src/utils/math.js';

clamp(15, 0, 10);   // 10
sum([1, 2, 3]);     // 6
average([2, 4, 6]); // 4
```

---

### clamp(n, lo, hi)

값 `n`을 하한 `lo`와 상한 `hi` 사이로 **가두어(clamp)** 반환한다.

#### 시그니처

```js
clamp(n: number, lo: number, hi: number) → number
```

#### 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `n`  | `number` | 예 | 가둘 대상 값 |
| `lo` | `number` | 예 | 하한 (최솟값) |
| `hi` | `number` | 예 | 상한 (최댓값) |

#### 반환값

| 타입 | 설명 |
|------|------|
| `number` | `lo <= n <= hi` 범위로 보정된 값 |

#### 동작 상세 및 엣지 케이스

- `n < lo`이면 `lo`를 반환한다.
- `n > hi`이면 `hi`를 반환한다.
- `lo <= n <= hi`이면 `n`을 그대로 반환한다.
- `n`이 경계값과 정확히 같으면 그 값을 그대로 반환한다.

#### 예시

```js
clamp(15, 0, 10);   // 10  (상한 초과)
clamp(-3, 0, 10);   // 0   (하한 미만)
clamp(5, 0, 10);    // 5   (범위 내)
clamp(0, 0, 10);    // 0   (경계값)
```

### sum(arr)

숫자 배열의 **총합**을 반환한다.

#### 시그니처

```js
sum(arr: number[]) → number
```

#### 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `arr` | `number[]` | 예 | 합산할 숫자 배열 |

#### 반환값

| 타입 | 설명 |
|------|------|
| `number` | 배열 전체 요소의 합 |

#### 동작 상세 및 엣지 케이스

- **빈 배열 `[]`을 넣으면 예외 없이 `0`을 반환한다.**
- 요소가 하나뿐이면 그 값을 그대로 반환한다.
- 음수도 정상적으로 합산된다.

#### 예시

```js
sum([1, 2, 3]);     // 6
sum([-1, 1]);       // 0
sum([42]);          // 42
sum([]);            // 0  (빈 배열은 예외 없이 0)
```

---

### average(arr)

숫자 배열의 **평균(산술 평균)**을 반환한다.

#### 시그니처

```js
average(arr: number[]) → number
```

#### 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `arr` | `number[]` | 예 | 평균을 계산할 숫자 배열 |

#### 반환값

| 타입 | 설명 |
|------|------|
| `number` | 요소 합 ÷ 요소 개수 (산술 평균) |

#### 동작 상세 및 엣지 케이스

- **빈 배열 `[]`을 넣으면 `RangeError`를 throw한다.** (0으로 나누기 방지)
- 요소가 하나뿐이면 그 값 자체가 평균이 된다.
- 나누어 떨어지지 않으면 부동소수점 결과를 반환한다.

#### 예시

```js
average([2, 4, 6]);  // 4
average([5]);        // 5
average([1, 2]);     // 1.5

try {
  average([]);
} catch (err) {
  console.error(err instanceof RangeError); // true
}
```
