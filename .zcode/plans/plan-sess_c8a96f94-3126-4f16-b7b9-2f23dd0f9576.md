# CryptoBot Pro — 자비스 음성 명령 + 시각화 레이어 구축 계획

## 전제 (탐색으로 확인된 사실)
- 백엔드는 FastAPI 5개 파일(~430줄). 엔진은 freqtrade를 서브프로세스로 래핑. `/ws/live`는 1Hz 상태만 전송(시세·손익 없음)
- **`license_manager.py`에 `List` 임포트 누락 → 현재 서버 기동 자체가 크래시** (수정 필수)
- `/api/profit`, `/api/trades`는 하드코딩 스텁 → 옆의 freqtrade(REST API localhost:8080 활성화됨)에서 실데이터를 가져오도록 교체
- 프론트엔드는 디렉터리만 있고 완전 비어있음 → Vue 3 + Vite + Pinia로 신규 구축 (백엔드 CORS에 5173 이미 등록됨)
- 확정된 선택: 음성=브라우저 Web Speech API(어댑터 구조), 인텐트=규칙 기반 한국어 매칭(LLM 자리 남김), 시각화=대시보드 통합 오브 + 풀스크린 페이스 둘 다

## Phase 0 — 기동 가능하게 (선행 필수)
1. `backend/auth/license_manager.py`: 타이핑 임포트에 `List` 추가 (기동 크래시 수정)
2. backend venv에 requirements.txt 설치
3. uvicorn(:8000) 기동 + `/api/status` 응답 확인

## Phase 1 — 백엔드: 실데이터 + 음성 명령 API
1. **`backend/services/freqtrade_client.py`** (신규): httpx로 freqtrade REST(`/api/v1/profit`, `/trades`, `/status`) 호출. freqtrade 꺼져 있으면 기존 스텁 값으로 폴백하는 그레이스풀 설계
2. `engine.py`: `get_profit()`/`get_trades()`를 freqtrade_client 경유로 교체 (폴백 유지)
3. **`backend/voice/intent.py`** (신규): 규칙 기반 한국어 인텐트 라우터
   - 조회: 상태 / 수익 / 잔고 / 최근 거래 / 전략 목록 / 시세("BTC 가격" 등 심볼 추출)
   - 제어: 시작 / 중지 / 전략 선택(안전형·균형형·공격형)
   - 미매칭 → 사용 가능한 명령 안내. 인터페이스는 LLM 어댑터 교체 가능 구조
4. `routes.py` 추가:
   - `POST /api/voice/command` `{text}` → 인텐트 실행 → `{reply(한국어 자연문), intent, data}`
   - `GET /api/market/tickers?pairs=...` → ccxt fetch_tickers (잔고 조회가 이미 쓰는 ccxt 패턴 재사용)
5. `websocket.py` 확장 — 메시지 타입 추가: `voice_state`(idle/listening/thinking/speaking, 클라이언트가 보고하면 전 창 동기화), `market`(티커 5초 주기), `profit`(요약 10초 주기). 기존 1Hz status 유지, 다중 접속 시 중복 브로드캐스트 정리

## Phase 2 — 프론트엔드: Vue 3 + Vite + Pinia 신규 구축
1. 스캐폴드(package.json, vite.config, router, Pinia) + `src/api/client.js`(REST 래퍼) + `src/composables/useLiveSocket.js`(/ws/live 재접속·디스패치)
2. **음성 레이어** `src/composables/useSpeech.js`: STT(webkitSpeechRecognition ko-KR, 푸시토크 버튼 기본 + 선택적 웨이크워드 "자비스" 연속모드), TTS(speechSynthesis 한국어 음성), 마이크 없는 환경용 텍스트 입력 대체 경로. 백엔드 엔진으로 교체 가능한 어댑터 계약
3. **`JarvisOrb.vue`** (Canvas 2D): idle=호흡 펄스 / listening=마이크 진폭 반응(WebAudio AnalyserNode) / thinking=회전 세그먼트 / speaking=TTS 싱크 파형 / 손익 틱=녹·적 외곽 펄스
4. **대시보드 `/`**: 오브 + 상태·잔고·수익·최근거래 카드 + 전략 선택 + 시작/중지 버튼 + 음성 명령 로그
5. **풀스크린 페이스 `/face`**: 큰 오브 전체화면 + 최소 HUD(상태, P&L). 같은 WS·음성 상태 공유로 두 화면 동시 반응
6. 다크 테마, 한국어 UI

## Phase 3 (이번 작업 제외, 후속 예정)
Electron 패키징+마이크 권한, LLM 인텐트 어댑터, freqtrade DB 직접 읽기

## 검증 방법
- 백엔드: 기동 후 curl로 전 엔드포인트 확인 (freqtrade 꺼짐=폴백 / 켜짐=실데이터 양쪽), 인텐트 매핑은 python 스크립트로 주요 발화 패턴 검증
- 프론트엔드: dev 서버 구동, 개발용 상태 강제 전환 버튼으로 마이크 없이 오브 애니메이션 확인, 텍스트 명령→음성 응답 전체 흐름 점검
- 실제 마이크/스피커는 Chrome에서 사용자가 최종 확인 (localhost는 HTTPS 없이도 마이크 허용됨)
