개인정보처리방침

최종 업데이트: 2026년 2월 28일

1. 개요

Anbu("당사")는 사용자의 개인정보를 중요하게 생각하며, 본 개인정보처리방침은 당사가 사용자의 개인정보를 수집, 사용, 보호하는 방법을 설명합니다.

2. 수집하는 정보

계정 정보

  • 이름 (실명 또는 별명)
  • 이메일 주소
  • 전화번호 (선택)
  • 프로필 사진 (선택)

사용 데이터

  • 안부 전송 기록
  • 앱 사용 패턴
  • 위치 정보 (SOS 시에만)
  • 기기 정보 (모델, OS 버전)

3. 정보 사용 목적

  • 가족 안부 서비스 제공
  • SOS 긴급 알림 발송
  • 서비스 개선 및 분석
  • 고객 지원
  • 보안 및 사기 방지

4. 정보 공유

당사는 다음의 경우에만 정보를 공유합니다:

  • 사용자가 지정한 가족 구성원
  • 법적 요구가 있는 경우
  • 사용자의 동의를 받은 경우

5. 데이터 보관

사용자 데이터는 계정이 활성화된 동안 보관되며, 계정 삭제 후 30일 이내에 삭제됩니다.

6. 사용자 권리

  • 개인정보 열람 및 수정
  • 데이터 내보내기
  • 계정 삭제
  • 마케팅 수신 거부

7. 보안

당사는 다음과 같은 보안 조치를 취합니다:

  • 데이터 암호화 (전송 및 저장)
  • 접근 통제
  • 정기적인 보안 감사

8. 아동 보호

만 14세 미만 아동의 개인정보는 법정대리인의 동의 없이 수집하지 않습니다.

9. 연락처

개인정보 관련 문의:

  • 이메일: privacy@anbu.app
  • 주소: 대한민국 서울특별시

10. 정책 변경

본 정책은 변경될 수 있으며, 변경 시 앱 내 알림으로 공지합니다.
